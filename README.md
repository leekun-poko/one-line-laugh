A tiny, dependency-free Python program that writes one funny line: a planner bought to help its owner finish things becomes the most beautifully organised thing its owner has never finished. The output is a single line of UTF-8 text, byte-for-byte deterministic.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The program writes `entry.txt` to /output in the grader, or to $MAKEFUN_OUTPUT_DIR outside a container.
